# 活用例

新規制作はテスト用の `.blend` で試し、変更範囲をプロンプトに書きます。以下は指示例です。

## シーンを読み取る

~~~text
Blender MCP を使って、シーンのオブジェクト名、種類、位置、寸法を一覧にしてください。
オブジェクトやファイルには変更を加えないでください。
~~~

## ゲーム用の螺旋階段を試作する

~~~text
新規コレクション StairPrototype に、ローポリの螺旋階段を作ってください。
段数は12。既存のコレクションとオブジェクトは編集しないでください。
作成後に外形寸法とおおよその三角形数を報告してください。
~~~

## Roblox 向けのモデルを点検する

~~~text
選択したモデルの三角形数、マテリアル数、寸法、原点、法線を確認し、
Roblox Studio への取り込み前に直したい点を報告してください。編集はまだ行わないでください。
~~~

取り込み後はテスト用の Studio プレースでスケール、見た目、当たり判定を確認します。Blender MCP と Studio MCP はそれぞれのアプリを操作し、アセットの引き渡しはエクスポートとインポートで行います。
