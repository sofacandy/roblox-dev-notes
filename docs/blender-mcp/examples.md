# 接続できたら試せること

次の例はそのまま Codex に送れます。物を作る例は、新しい Blender ファイルか、元のファイルを別名で保存したコピーで試してください。

## 今開いているシーンを調べる

~~~text
Blender MCP を使って、いま開いているシーンにある物の名前、位置、大きさを教えてください。
シーンやファイルは変更しないでください。
~~~

## ゲームに置く階段を試しに作る

~~~text
Blender MCP を使って、段数が12の、形がシンプルな螺旋階段を作ってください。
StairPrototype という新しいコレクションに入れ、すでにある物は変更しないでください。
できたら、階段の高さと幅を教えてください。
~~~

コレクションは、Blender の中で物をまとめる入れ物です。

## Roblox Studio に持っていく前に確認する

~~~text
選んでいるモデルの大きさ、中心の位置、面の向きを確認してください。
Roblox Studio に持っていく前に直した方がよい所があれば教えてください。
まだ編集はしないでください。
~~~

モデルをファイルに書き出して Studio に読み込んだら、テスト用の場所に置き、見た目やキャラクターとの大きさの違いを確認します。
