# Rojo

Rojo はファイルと Roblox Studio 内のインスタンスを対応づける開発ツールです。Luau を外部エディタで編集し、Studio のプレイテストと Git のレビューを組み合わせられます。

!!! note "検証状況"
    この章は公式 v7 ドキュメントに基づく例です。今回の Windows 環境で、CLI の導入から Studio の同期・プレイテストまでの通し検証は未実施です。
